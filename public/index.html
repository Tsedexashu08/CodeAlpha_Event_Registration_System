API Endpoints

Complete RESTful API for managing events and registrations

Method Endpoint Description Access
GET /api/events Retrieve all events Public
GET /api/events/:id Get specific event details Public
POST /api/events Create a new event Organizer/Admin
POST /api/registrations Register for an event Authenticated Users
GET /api/registrations/my-registrations View user's registrations Authenticated Users
DELETE /api/registrations/:id Cancel a registration Authenticated Users
POST /api/auth/register Register a new user Public
POST /api/auth/login User login Public
